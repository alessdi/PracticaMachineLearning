Clasificación de frijol seco por visión artificial

Una cámara mide 16 características geométricas de cada grano y la red decide a cuál de las 7 variedades pertenece. Dataset Dry Bean (UCI), 13 611 granos.

  • Red MLP 16 → 128 → 64 → 7 (ReLU, BatchNorm, Dropout, softmax)
  • Exactitud en prueba 92.70 %

Modifica cualquier medida y la red vuelve a clasificar al instante.

Potencia eléctrica de una central de ciclo combinado

La red estima la potencia neta por hora que entrega la planta a carga completa a partir de cuatro variables ambientales. Dataset Combined Cycle Power Plant (UCI), 9 568 registros.

  • Red MLP 4 → 128 → 64 → 32 → 1 (ReLU, salida lineal)
  • Prueba R² = 0.948 · RMSE = 3.88 MW

Mueve los controles para cambiar las condiciones ambientales.

Detección de fallas en motores con series de tiempo

Cada ejemplo son 500 lecturas del sensor de ruido de un motor automotriz en la prueba de fin de línea. La red convolucional decide si el motor tiene una falla. Dataset FordA (UCR Archive).

  • Red FCN: 3 × [Conv1D 64 filtros, kernel 7 + BatchNorm + ReLU] → GAP → softmax
  • Exactitud en prueba 93.79 % (1 320 series)
